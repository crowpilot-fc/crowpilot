# Fixed-wing plane

Conventional fixed-wing plane support is on the roadmap, not in v1.0.

- **v1.1** adds a plane stabilization subsystem and a twin-engine cargo plane mixer (the Caribou airframe).
- **v1.2** adds a single-engine plane mixer (the Gee Bee airframe).

See the [Roadmap](../roadmap.md) for the full plan. This page will be filled in when plane support ships.
